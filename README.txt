HOW TO PREVIEW ON ANDROID
1. Extract the ZIP file in your Downloads folder.
2. Open index.html with a browser or a local HTML viewer. Some Android file managers may not run local pages directly.
3. For the most reliable preview, upload the extracted index.html to a static hosting provider.

HOW TO PUBLISH
1. Choose and register a domain after checking availability and renewal cost.
2. Upload index.html to a static hosting provider such as GitHub Pages, Netlify, or Cloudflare Pages.
3. Follow that provider's current instructions to connect your domain and enable HTTPS.
4. Test on mobile, desktop, and multiple browsers.
5. Replace the brand concept copy with final approved content and contact information before public launch.

IMPORTANT LIMITATIONS
- This is a static front-end starter, not a complete production financial service.
- No user accounts, server/database, payment processing, live prices, broker execution, email signup, or secure backend are included.
- Lesson progress is stored only in the current browser on the current device and can be cleared by browser settings.
- The brand name/domain and any regulatory requirements have not been verified.
